## 🚀 Пет-проект: автоматизация разметки банковских операций

Разработал скрипт на **JavaScript** для автоматического распределения банковских операций по **типам и категориям** в бухгалтерском сервисе Альфа-Банка.

Необходимость проекта возникла из-за некорректной и неполной автоматической разметки операций со стороны банка, что напрямую влияло на корректность подготовки **деклараций о доходах и расходах** для налоговой.

### Что сделано:
- Реализована логика автоматической классификации операций
- Обработаны кейсы некорректной и частично заполненной разметки
- Снижена необходимость ручной корректировки данных

### Технологии:
- **JavaScript**
- Автоматизация бизнес-логики
- Работа с финансовыми данными

### Результат:
- Повышение точности данных для налоговой отчётности
- Сокращение ручной работы и человеческих ошибок
- Практическое применение автоматизации в реальном бизнесе
